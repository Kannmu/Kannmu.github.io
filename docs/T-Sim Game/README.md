# T-Sim · 做T训练场

用**真实的 A 股与 ETF 分钟级历史行情**做回放，一轮就是一个交易日。

它想解决的问题很具体：做T的难点不在于看懂 K 线，而在于**在分时图还在往右画的时候做决定**。看历史图谁都知道该在哪里买、在哪里卖；实盘里你不知道后面会发生什么。所以这个训练器把未来藏起来，只给你已经走出来的那一段，逼你在信息不完整的情况下出手，然后立刻告诉你这一手值多少分。

## 它训练什么

| 训练目标 | 对应机制 |
| --- | --- |
| 认出今天是什么日子 | 每天收盘后自动打形态标签（单边上涨 / 单边下跌 / 宽幅震荡 / 窄幅盘整 / 探底回升 / 冲高回落），统计页按形态拆解你的胜率与平均收益 |
| 分清正T与倒T | 引擎完整实现 T+1：当天买入的股票当天不能卖，所以「先买后卖」只能用底仓额度，逼你理解底仓的意义 |
| 均价线（VWAP）直觉 | 分时图常驻均价线，教练实时报乖离率（bp），提示均值回归窗口 |
| 仓位纪律 | 下单规模固定为底仓的 ¼ / ⅓ / ½ / 全部，默认推荐区间；单笔超过底仓会被标记 |
| 成本意识 | 完整的费用模型（佣金双边 + 每笔最低 5 元、印花税卖出、过户费），下单面板常驻显示**往返盈亏平衡幅度** |
| 复盘能力 | 收盘后逐笔评分（成交之后价格朝有利方向运行的比例）、理论最优单次往返、捕获率、坏习惯清单 |

## 设计上的几个取舍

**为什么不给「加速看完历史」的模式。** 看已经画完的图学不到东西——那是阅读，不是判断。所以任何一局里未来都不可见，你只能在信息不完整时出手。

**为什么一轮只做一个交易日，而不是一条连续的资金曲线。** 做T的手感是「今天这一波该不该动」，不是长期复利。把一轮压缩成一个交易日，反馈周期从几个月缩到几十秒，练的是同一块肌肉，但当场就知道对错。

**为什么收盘后要逐笔打分。** 赚钱的一手也可能是坏习惯（追高买在最高点，恰好后面还在涨），亏钱的一手也可能是好决策。评分看的是「成交之后价格朝有利方向运行的比例」，而不是结果本身，这样才不会把运气练成习惯。

**为什么把费用摆在最显眼的位置。** 默认设置下，一次 10 万元的往返要 152 元，需要 0.152% 的涨幅才能打平；而当单笔金额降到 1 万元以下，最低 5 元佣金会让成本占比翻好几倍。这个数字直接决定了「小仓位频繁做T」是负期望的——不看它，做T就只是给券商打工。

**为容易走神做的适配。** 一轮 30 秒左右（速度可调）；关键操作全部有快捷键；「跳到下一个关键点」跳过没有信息的横盘；结算给的是 S/A/B/C/D 评级、音效和逐笔点评，而不是一堆数字；按 `N` 直接进下一轮，中间没有加载页和菜单；难度跟着表现自动升降，避免太简单无聊、太难挫败。

## 玩法

1. 你手上已经有一笔**底仓**（默认约 10 万元市值），和一个交易日的分时图。
2. 行情自动向右推进，可暂停、单步、或跳到下一个关键点。
3. 随时下单：
   - **正T**：低点买入，之后卖出等量底仓，差价落袋；
   - **倒T**：高点先卖底仓，之后低位买回。
4. 15:00 收盘结算，得到 S/A/B/C/D 评级与逐笔复盘。
5. 「下一轮」立刻开始新的一天——数据已预加载，没有等待。

### 快捷键

| 键 | 作用 |
| --- | --- |
| `空格` | 暂停 / 继续 |
| `→` | 单步前进一根 K 线 |
| `B` / `S` | 按当前选中的规模买入 / 卖出 |
| `1` `2` `3` `4` | 选择 ¼ / ⅓ / ½ / 全部 |
| `F` | 跳到下一个关键点 |
| `↵` | 收盘结算（结算后为「下一轮」） |
| `N` | 结算后直接进入下一轮 |

### 模式

- **无尽模式**：按当前筛选随机抽取历史交易日，一轮接一轮。
- **每日挑战**：以当天日期为随机种子，任何人当天拿到同一个交易日。
- **专项训练**：只练某一种形态（例如「只练探底回升」）、某一类标的（股票 / ETF）、某一种 K 线周期（1 分钟 / 5 分钟）。
- **自适应难度**：连续三轮高分自动加压，连续低分自动减压，保持心流区间。

## 真实性的边界

实现上刻意贴近 A 股规则，以下都是引擎里真实生效的约束，不是文案：

- **T+1**：当日买入冻结，`可卖 = 持仓 - 当日买入`。跨境 ETF（513xxx）、债券 / 货币 ETF（511xxx）、黄金 ETF（518xxx）等识别为 **T+0**，可当日回转，界面上有角标。
- **涨跌停**：主板 ±10%、创业板 / 科创板 ±20%、ST ±5%。**一字板买不进 / 卖不出**（bar 的最高价等于最低价且等于涨跌停价时拒单）。
- **费用**：佣金双边按费率收取、每笔最低 5 元；印花税仅卖出、仅股票；过户费双边。默认按题设「万分之五 + 最低 5 元」。全部参数可在设置里改，并实时预览成本。
- **最小变动单位**：股票 0.01 元，ETF 0.001 元；下单必须是 100 股（份）整数倍。
- **成交价**：以当前 K 线收盘价成交，可选滑点。
- **昨收锚点**：底仓成本按昨收计，今日盈亏从 0 开始，注意力集中在今天的操作上。

刻意简化的部分：不模拟盘口五档与逐笔成交、不模拟集合竞价撮合、不考虑分红除权对跨日持仓的影响（每个交易日的回放都是独立的）。

## 数据

`public/data/` 里是与站点一起发布的真实历史数据，来自公开行情接口：

- **5 分钟 K 线**：每个标的 31 个完整交易日
- **1 分钟分时**：每个标的 4 个交易日（接口只提供最近几日，重跑脚本可累积更多）
- **日线**：每个标的最近 180 根，用作上下文（近 10 日走势、位置判断）
- 合计 **159 个标的、5565 个可玩交易日场景**，约 9 MB（按标的**懒加载**，单轮约 13 KB）

标的覆盖 110 只股票（主板 / 创业板 / 科创板，含大盘蓝筹与高波动个股）与 49 只 ETF（宽基、行业、跨境、债券、黄金、货币，其中 19 只支持 **T+0**）。标的日均振幅分布：10 分位 1.6%、中位数 4.3%、90 分位 7.0%、最高 11.0%。

### 重新下载 / 追加最新交易日

```bash
npm run data:fetch                        # 默认 110 只股票 + 50 只 ETF
npm run data:fetch -- --stocks 40 --etfs 20
npm run data:fetch -- --only 600519,510300
```

- 原始响应缓存在 `tools/.cache/raw`，脚本**可断点续跑**：重复运行只会补下失败或缺失的部分，已成功的瞬间完成。
- 想拉到更新的交易日，删掉 `tools/.cache/raw` 再跑一次即可。
- 行情接口对并发比较敏感，如果失败较多，用 `--concurrency 2` 再跑一次。
- 如果在需要代理的网络里，脚本会自动检测 `HTTP_PROXY` / `HTTPS_PROXY` 并用 Node 的 `--use-env-proxy` 重启自己。

## 开发

```bash
npm install
npm run dev          # http://localhost:5175
npm test             # 28 个单元测试，覆盖编解码 / 费用 / T+1 引擎 / 评分 / 形态识别
npm run build        # 产物写入 ./dist
npm run serve:dist   # 按线上路径预览 dist（含 %20 转义）
```

技术栈与仓库内其它工具保持一致：**Vue 3 + Vite 7**，无额外运行时依赖（图标用 `lucide-vue-next`，图表是手写 Canvas，没有引入图表库）。

```
src/
  core/            纯逻辑，全部可单测，不依赖 Vue
    codec.js       厘整数 + 差分编码，体积减半
    engine.js      行情回放引擎：T+1、涨跌停、费用、持仓
    fees.js        费用模型与盈亏平衡
    scoring.js     结算、评级、逐笔评分、坏习惯识别
    patterns.js    日内形态分类与单笔决策评分
    coach.js       实时教练（只用已走出的数据，不剧透）
    scenario.js    场景筛选与抽查
  composables/
    useGame.js     单例状态机：设置、生涯进度、轮次生命周期、播放时钟
  components/      Canvas 分时图、交易面板、结算卡等
  views/           首页 / 对局 / 统计 / 设置
tools/
  fetch-data.mjs   行情下载与打包
  serve-dist.mjs   按线上路径预览构建产物
```

### 教练不剧透

`src/core/coach.js` 里所有提示只读取 `session.barIndex` 之前的数据（均价线乖离、当日已走出的区间位置、时段、T+1 冻结数量、费用），任何一条都不会引用未来 K 线。这是整个训练价值的底线，改动这个文件时请保持。

## 部署

与本仓库其它独立工具一致：源码与构建产物 `dist/` 一起提交，随 `docs/` 目录由 GitHub Pages 发布。

```bash
npm ci && npm test && npm run build
```

提交整个 `dist/` 目录后即可访问：

```
https://kannmu.top/T-Sim%20Game/dist/
```

> 目录名里有一个空格，所以线上路径是 `T-Sim%20Game`。正是为了这个，生产构建使用**相对 base**（`.env.production` 中的 `VITE_BASE_PATH=./`），所有资源与数据请求都相对于 `index.html` 解析，路径里带空格、改名或换目录都不会失效。若需要固定绝对路径，改成 `VITE_BASE_PATH=/T-Sim%20Game/dist/` 重新构建即可。
>
> 不要直接把源码目录里的 `index.html` 当入口，也不要手动改 `dist/index.html`——Vite 会把 base 同时写进入口文档和打包后的资源引用里，只改一处会导致资源 404。

## English summary

T-Sim is a browser trainer for **intraday T-trading (做T) on the Chinese A-share market**. Each round replays one real historical trading day of one real stock or ETF, candle by candle, with the future hidden. The engine enforces the rules that actually matter: T+1 share freezing (T+0 for cross-border / bond / gold ETFs), price limits with locked-board rejections, 100-share lots, and the full Chinese fee stack including the 5 CNY minimum commission. After the close it grades every fill against what happened next, compares your result with the best single round trip the day allowed, labels the day's shape, and tracks the habits that cost you money over time.
