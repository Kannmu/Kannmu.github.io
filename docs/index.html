研究方法以原型开发与受控实验为主：先搭建可运行的软硬件系统，再测量操作绩效、错误率与主观负荷，并将结果整理为可复用的设计参数。 The method pairs prototype development with controlled studies: a working system is built first, then performance, error rate and perceived workload are measured, and the results are distilled into reusable design parameters.
