# PhoLo

PhoLo 是一个完全在浏览器本地运行的多图排版工作台。它只对图片做平移和等比例缩放，不裁剪、不拉伸、不重叠，并将统一的留白间隙直接纳入几何求解。图片不会上传服务器。

## 使用

```bash
npm ci
npm run dev
```

生产构建和测试：

```bash
npm test
npm run build
```

`dist/` 是可发布的静态站点产物。默认资源基路径是 `/PhoLo/`；部署到其他路径时设置 `VITE_BASE_PATH` 后再构建。

## 算法要点

PhoLo 将布局限制在 slicing floorplan，也就是由水平或垂直二叉切割构成的矩形树。对任意子树，宽度都可写成 `W = aH + bg`，其中 `g` 是全局 gap。合并、搜索和坐标回溯都只使用这个仿射关系，因此每条内部缝隙都严格一致。选择固定画幅时，画布外框严格保持该比例，排版在不裁剪、不拉伸的前提下居中放入画布；无法无损铺满时保留必要的背景余量。

搜索采用固定种子的多起点构造和模拟退火，突变包含交换图片、翻转切割方向、树旋转和随机重启。代价函数同时考虑图片视觉面积均衡、目标画幅、过小或过大的尺寸极端值。搜索在 Web Worker 中运行，主线程只接收节流后的最佳候选。

切片树是有意做出的速度与可证明约束之间的取舍。它不声称覆盖所有可能的矩形剖分，但能保证无重叠、无裁剪、统一 gap 和矩形外框。
