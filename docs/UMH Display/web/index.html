UMH Display 使用说明

这是什么

84 路 40 kHz 超声相控阵朝下发射，在桌面形成驻波，把一颗 3 mm 泡沫小球托在桌面上方约 2.3 mm 处。阵列每帧重算相位，让陷阱沿规划好的路径高速移动；泡沫球被 4 颗 WS2812 照亮，靠视觉暂留画出彩色图形。

光绘流程

  1. 连接设备；没有硬件时留在演示模式，同样可以规划和预览。
  2. 「起浮 / 接管」打开陷阱，把小泡沫球放进声场。
  3. 选图形、尺寸和颜色，点「规划」。默认会做速度规划、抗共振滤波、前馈与仿真验证；打开「解除所有限制」则直接生成原始轨迹。
  4. 点「播放」开始画图；「停止」沿路径减速后原地悬停，「落球」关场。
  5. 第一次画图前建议先做 spin test：让小球在 8 mm 圆上加速旋转，甩出时点一下，程序反解 255 级下的横向陷阱强度。

解除所有限制

顶部「模式」里的开关会把规划器整体旁路：轨迹按图形几何直接采样，陷阱位置就是目标位置，不做前馈、TOPP、jerk 限制、抗共振滤波或小球动力学仿真。

  • 基础周期是固件循环长度，范围 1 ms – 60 s。
  • 播放速度是固件 0.001× – 1× 的速率分频，播放中也可以实时调整。
  • 两者组合后实际一圈可从 1 ms 到约 16.7 小时；例如 16.7 小时的圆平均速度只有约 0.0008 mm/s，适合带动其他对象或极慢曝光。
  • 设备端使用同一条 MOTION_PATH 通路，强制线性插值；关闭开关即恢复原来的规划模式，两者互不覆盖。

硬边界只有固件路径点数（旧固件 255、v7.4 为 1024）和 60 s 循环长度；没有软件层速度、加速度或形状误差限制。

浏览器要求

三维视图需要 WebGL 2。连接真实硬件需要 Chrome / Edge 的 Web Serial，并且页面必须通过 HTTPS 或 localhost 打开（本页上线地址满足要求）。串口自动识别 STM32 CDC（VID 0483 / PID 5740）。

关于模型

本页是原 Python 桌面程序的浏览器重构：声场 / Gor'kov 势、陷阱模型、速度规划、抗共振滤波器、固件路径插值与协议编解码均按原实现逐行移植，并用 Python 生成的黄金数据做单元测试。规划结果只作提示，真实小球的安全由操作者判断。
